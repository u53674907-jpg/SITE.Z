# SITE.Z
A comprehensive construction feasibility analysis such as :
 -The hydrology of a site,
-The vegetation on the site
- The topography
-The rocks on the site
-Public Circulation
-Elevation changes
-Historic Data 
-Future Data
-Thermal Dynamics of the site
-Climate Change
- Flood Risk 
-Fire Risk
-Air Pressure
-Wind Direction
-Average Wind speeds 
-Construction Cost and land value
-Erosion
-Weather patterns 
-Weathering
-Elevation
And Many other things Architects, Quantity Surveyors and relevant Engineers would have to consider.
